Este repositorio contiene la documentación técnica, ejercicios prácticos y proyectos desarrollados durante el **Bootcamp de Inteligencia Artificial** (Programa Talento Tech / MinTIC), perteneciente al **Grupo G340**.

El objetivo de este portafolio es demostrar el dominio de conceptos fundamentales de programación, análisis de datos y creación de modelos de aprendizaje automático.

## 📂 Estructura del Repositorio

El contenido está organizado de forma modular según el avance del curso:

### 1. 🐍 Fundamentos y Análisis de Datos (`/Mision1y2`)
En esta sección se encuentran los primeros desafíos técnicos enfocados en la lógica de programación y la manipulación de datos.
* **Temas abordados:**
    * Estructuras de datos en Python (Listas, Diccionarios, Tuplas).
    * Limpieza y transformación de datos con **Pandas**.
    * Operaciones numéricas y matriciales con **NumPy**.
    * Ejercicios de lógica algorítmica.

### 2. 🤖 Machine Learning y Modelado (`/Mision3`)
Contiene el proyecto de profundización o reto final del módulo, donde se aplican algoritmos para resolver un problema basado en datos.
* **Temas abordados:**
    * Análisis Exploratorio de Datos (EDA).
    * Visualización de datos (Matplotlib/Seaborn).
    * Implementación de modelos de Machine Learning (ej. Regresión/Clasificación).
    * Evaluación de métricas de desempeño del modelo.

### 3. 📄 Perfil Profesional Web (`/MiHojaVida`)
Proyecto introductorio para el aprendizaje de control de versiones y despliegue web básico.
* **Tecnologías:** HTML5, CSS3.
* **Objetivo:** Práctica de flujo de trabajo con Git (commit, push, ramas) y GitHub Pages.

### 4. 📚 Material de Apoyo (`/DocumentoBase`)
Recursos teóricos, guías de los retos y documentación complementaria suministrada durante el bootcamp.

* **Lenguajes:** Python, HTML.
* **Librerías de Ciencia de Datos:**

## 💻 Cómo ejecutar este proyecto

Para visualizar y ejecutar los cuadernos de código (`.ipynb`):

1.  **Clonar el repositorio:**
    ```bash
    git clone [https://github.com/cviloriam/Bootcamp-G340-IA-MinTic-2025.git](https://github.com/cviloriam/Bootcamp-G340-IA-MinTic-2025.git)
    ```
2.  **Instalar dependencias:**
    Asegúrate de tener Python instalado y ejecuta:
    ```bash
    pip install pandas numpy matplotlib seaborn scikit-learn jupyter
    ```
3.  **Iniciar Jupyter Notebook:**
    ```bash
    jupyter notebook
    ```
    Navega a las carpetas `Mision1y2` o `Mision3` para abrir los archivos.
